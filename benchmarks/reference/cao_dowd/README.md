# Cao–Dowd reference inputs

Source: [jcao0/synthetic-control-spillover](https://github.com/jcao0/synthetic-control-spillover),
commit `86004020a248c7ee18f3c8a68b1e41db6abc0dda`, for
[Cao and Dowd, arXiv:1902.07343v4](https://arxiv.org/html/1902.07343v4).

- `scspill/data/files/cao_dowd/cigs_consumption.csv` and `state_list.csv` are
  copied from `replication files/application/prop99 spillover 51 units/data/`.
  These are the CDC-based public-domain input data: 50 states plus DC,
  1970–2000, with treatment beginning in 1989. They are distinct from the
  package's older 39-state, 1988-onward California panel.
- `results_51.json` and `results_41.json` are the authors' frozen application
  outputs in the respective `prop99 spillover * units/output/` directories.
- `inference_replication_1.npz` contains the six first-replication outcome
  panels generated by the authors' inference DGP and the corresponding
  SP-A direct-effect estimates at effect 5 from
  `inference/provenance/published_estimates.npz`. The settings are stationary
  and integrated factors, each at pure-donor distance $r=0,0.5,1$.
- `loo_reference_stationary_r05_rep1.npy` holds all 50 squared SP-A
  leave-one-pre-period-out reference statistics for the stationary, $r=0.5$
  first inference replication. They were independently generated by the
  authors' `inference/src/procedures.py::andrews_loo_references` at the same
  pinned commit. The slow estimator test compares all 50 statistics.
- `kappa_rep1.json` records the author's range and homogeneous-structure
  $\kappa_A$ statistics and all 50 full-sample reference values on the
  stationary, $r=0.5$ first inference panel. The statistic was generated with
  `kappa_a/src/structures.py` and the fitted SCM equations with
  `inference/src/scm.py` at the pinned commit.
